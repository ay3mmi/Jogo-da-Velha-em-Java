Para conseguir jogar o jogo da velha instale a extensão do vscode "Extension Pack for Java" da Microsoft por que isso vai falicitar muito para poder rodar o programa, já que com essa extenção ele já vem com um botão de inicialização do código.

Se optar por não instalar essa extenção e so abrir o terminal (Ctrl + Shift + ") do vscode e digitar "java JogoDaVelha" que assim você consegue rodar o código também.
